
# FuelConnect Nigeria Backend

This folder contains the backend setup and security documentation for FuelConnect Nigeria.

## Main objectives
- Secure Firebase Authentication
- Super Admin and Admin role management
- Role-based permissions
- Firestore security rules
- Admin activity audit logs
- Shared backend for Web and Android applications

## Security
All privileged operations must be performed through trusted backend services.

Never store passwords, private keys, or service account credentials in this repository.
